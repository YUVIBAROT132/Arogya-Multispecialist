Arogya Multispecialty Hospital - Hospital Information Website
PBL Micro Project | Web Application Development (BE05000281) | GTU

How to run: unzip and double-click index.html. No server or internet needed.

Pages (10): index, about, departments, doctors, services, packages,
appointment, patients, tips, contact.
Folders: css/style.css (design system), js/ (data.js holds all sample data).
All hospital, doctor and testimonial content is fictional sample data.
No real phone numbers, emails or addresses are used anywhere.
